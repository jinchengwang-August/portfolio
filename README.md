# August Wang — Interactive Portfolio

[![Live website](https://img.shields.io/badge/Live%20website-Visit-d3382a?style=for-the-badge)](https://august-wang-portfolio-jinchengwang-augusts-projects.vercel.app/)
[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-11110e?style=for-the-badge&logo=vercel)](https://vercel.com/)

An experimental, single-screen portfolio presented as an interactive digital exhibition for **August Wang** — researcher, product builder, and student of human systems.

## The experience

The site does not use conventional vertical pages. Scrolling, swiping, keyboard navigation, and chapter controls move between a sequence of full-screen scenes. Each transition reshapes the composition like turning a page in an independent art catalogue.

The visual system uses paper white, ink black, and vermilion red, pairing editorial typography with restrained Canvas effects and kinetic transitions.

## Chapters

1. Opening
2. Interactive index
3. Experience and education
4. Selected products
5. Research
6. Life and interests
7. Coffee chat and contact

## Interaction

- Scroll or swipe to move between scenes
- Use arrow keys, Page Up, Page Down, or Space
- Select chapter markers for direct navigation
- Move the pointer to reveal subtle ink traces and typographic reactions
- Switch between a cultural archive and a light, living technology interface
- Pluck six playable guitar strings in archive mode
- Drag historical newspaper clippings around the composition
- Explore animated code, equations, signal graphics, and a research pipeline
- Respects the operating system's reduced-motion preference

## Technical approach

The site is intentionally lightweight:

- Semantic HTML
- Hand-authored responsive CSS
- Vanilla JavaScript
- Canvas-based pointer effects
- No framework
- No external font dependency
- Static Vercel deployment

## Run locally

Open `index.html` directly, or serve the directory with any static file server.
